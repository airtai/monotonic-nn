# monotonic-nn v0.4.0 mononet-shim — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-implement `monotonic-nn` as a deprecated, thin compatibility shim that depends on `mononet` and re-exports `mononet.legacy`, so existing `airt.*` imports keep working while the real implementation lives in mononet.

**Architecture:** Drop nbdev; convert to a plain hatchling `pyproject.toml`. The `airt/` package becomes hand-written re-export modules over `mononet.legacy`. `experiments.py` is kept as-is. Docs move from nbdev-mkdocs to plain mkdocs-material with per-page deprecation notices linking to the mononet docs.

**Tech Stack:** Python 3.11+, hatchling, `mononet>=0.0.0a1`, `tensorflow>=2.16` (provides Keras 3 + default TF backend), pytest, mkdocs-material + mkdocs-jupyter.

## Global Constraints

- `requires-python = ">=3.11"`. This is a deliberate break from the old 3.9–3.11 range.
- Runtime dependencies: exactly `["mononet>=0.0.0a1", "tensorflow>=2.16"]`. TF 2.16+ bundles Keras 3; do not add a separate `keras` pin.
- Package name stays `monotonic-nn`; import namespace stays `airt`. Version `0.4.0`.
- The public API surface must remain importable at the original paths: `from airt.keras.layers import MonoDense`, `MonoDense.create_type_1`, `MonoDense.create_type_2`, and the helpers from `airt._components.mono_dense_layer`.
- Re-exports must resolve to the **same objects** as `mononet.legacy` (`airt...MonoDense is mononet.legacy.MonoDense`). Do not re-wrap or subclass.
- `airt/keras/experiments.py` is kept **as-is** — do not edit it (Keras-3 compatibility is a separate follow-up).
- No nbdev: after this work, no file may carry a `# AUTOGENERATED! DO NOT EDIT` header, and `nbdev`/`nbdev-mkdocs` must not appear in any dependency list or workflow.
- Commit with `git commit --no-gpg-sign`. Work on branch `mononet-shim`; never commit to `main`.
- Installing for tests pulls the mononet alpha + TensorFlow: `pip install -e ".[test]"` (the `>=0.0.0a1` specifier permits the prerelease; if a resolver balks, use `pip install --pre -e ".[test]"`).
- mononet benchmark doc base for notices: `https://davorrunje.github.io/mononet/main/benchmarks/paper-reproduction/` (`auto-mpg.html`, `blog-feedback.html`, `compas.html`, `heart-disease.html`, `loan-defaulter.html`).

```python
"""The re-exported builders build runnable Keras models (upstream convention)."""

from __future__ import annotations

import warnings

import keras
import numpy as np

with warnings.catch_warnings():
    warnings.simplefilter("ignore", DeprecationWarning)
    from airt.keras.layers import MonoDense, create_type_1, create_type_2


def test_create_type_1_builds_runnable_model() -> None:
    inputs = [keras.Input(shape=(1,)) for _ in range(4)]
    out = create_type_1(
        inputs, units=8, final_units=1, activation="elu", n_layers=3,
        monotonicity_indicator=[1, 1, -1, 0],
    )
    model = keras.Model(inputs, out)
    xs = [np.zeros((2, 1), dtype="float32") for _ in range(4)]
    assert tuple(model(xs).shape) == (2, 1)


def test_create_type_2_builds_runnable_model() -> None:
    inputs = [keras.Input(shape=(1,)) for _ in range(4)]
    out = create_type_2(
        inputs, units=8, final_units=1, activation="elu", n_layers=2,
        monotonicity_indicator=[1, -1, 0, 1],
    )
    model = keras.Model(inputs, out)
    xs = [np.zeros((2, 1), dtype="float32") for _ in range(4)]
    assert tuple(model(xs).shape) == (2, 1)


def test_classmethods_reachable() -> None:

    assert callable(MonoDense.create_type_2)
```

`tests/test_forward.py`:

```python
"""A re-exported MonoDense runs a forward pass under the default backend."""

from __future__ import annotations

import warnings

import keras
import numpy as np
from keras import ops

with warnings.catch_warnings():
    warnings.simplefilter("ignore", DeprecationWarning)
    from airt.keras.layers import MonoDense


def test_monodense_forward_is_finite() -> None:
    layer = MonoDense(4, activation="relu", monotonicity_indicator=1)
    x = ops.convert_to_tensor(np.ones((3, 5), dtype="float32"))
    y = ops.convert_to_numpy(layer(x))
    assert y.shape == (3, 4)
    assert np.isfinite(y).all()
```
